Installation

Standard install (recommended · full better-sqlite3 backend)
git clone <repo> liuhe && cd liuhe/malong && npm ci && node mcp-server.js --workspace .
Build-free deploy (offline / sandbox · sql.js backend)
tar -xzf malong-liuhe-0.4.5-linux-x86_64.tar.gz && cd malong && node mcp-server.js --workspace .

Both paths offer identical features — only the index backend differs. On boot the tarball prints a SQLITE BACKEND upgrade hint; on a networked machine, cd malong && npm ci upgrades to the full backend.

FAQ

How does the MCP server start the parser?
Both npm ci and the tarball bundle the Rust parser binary (malong-parse); the server spawns it on boot. Parser panics are isolated via catch_unwind and never kill the MCP process.
Where is the index stored?
One SQLite file per workspace (WAL mode) under the workspace's .malong/ directory (gitignored). Corrupt databases self-heal via integrity_check rebuild.
Which languages support symbol-level writes?
read/write_symbol cover 10 language families: JS/TS/TSX/Python/Go/Rust/C-C++/Java/Bash. Writes are followed by automatic syntax checks (node --check / py_compile).
Do quality-gate tools call an LLM?
No. All quality/security tools are deterministic pure regex/AST implementations — same input, same output, always. Reproducible, CI-ready and auditable.
