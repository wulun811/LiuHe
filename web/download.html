解压即跑（3 步）

bash Linux / macOS 示例 
# 1) 解压
tar -xzf malong-liuhe-0.4.5-linux-x86_64.tar.gz
cd malong

# 2) 启动 MCP 服务器（sql.js 沙盒后端，启动时有升级提示）
node --max-old-space-size=4096 mcp-server.js --workspace /path/to/project

# 3) 校验完整性（可选）
sha256sum malong-liuhe-0.4.5-linux-x86_64.tar.gz

MCP 客户端配置

opencode.json
{
  "mcp": {
    "malong": {
      "type": "local",
      "command": ["node", "malong/mcp-server.js",
                  "--workspace", "."],
      "enabled": true
    }
  }
}

✓ 沙盒后端说明

tar 包内置 sql.js WASM 索引实现，无需任何编译即可运行，功能与 npm 完整版一致。 服务器启动时会打印 SQLITE BACKEND 提示： 在有网络的环境 cd malong && npm ci 即可升级到 better-sqlite3 完整后端。
